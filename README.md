🚀 ServeX - Real-Time Donation Platform

ServeX is a full-stack MERN application that connects Donors, NGOs, and Volunteers to simplify donation management through secure authentication, role-based access, and real-time updates.

✨ Features
🔐 JWT-based Authentication & Authorization
👥 Role-Based Dashboards (Donor, NGO, Volunteer)
📦 Create & Manage Donations
🤝 Volunteer Assignment & Tracking
⚡ Real-Time Notifications using Socket.IO
📊 Donation Status Tracking
🔒 Secure REST APIs with Express.js
📱 Responsive User Interface
